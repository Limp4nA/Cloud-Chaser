====================================
       CLOUD CHASER: README
====================================

Welcome to **Cloud Chaser**, a platformer game where you climb to new heights while avoiding obstacles and using strategic movement. This file contains information about the controls, cheat codes, and gameplay mechanics.

------------------------------------
          HOW TO PLAY
------------------------------------
Follow these steps to set up and play the game:

1. **Install Required Libraries:**
   - This game uses the Python library `Pillow` for image handling. You need to install it before launching the game.
   - Run the following command in your terminal:
     ```
     pip install pillow
     ```
   - If you're using Python 3, use:
     ```
     pip3 install pillow
     ```

2. **Launch the Game:**
   - Navigate to the directory containing the game files.
   - Run the game using:
     ```
     python3 game_solution.py
     ```
   - You can also use:
     ```
     python game_solution.py
     ```

3. **Enjoy the Game:**
   - Use the controls to climb as high as possible while avoiding obstacles and falling off the screen.


------------------------------------
            CONTROLS
------------------------------------
Customize your controls in the settings menu:
- **Move Left**: Default is `A`.
- **Move Right**: Default is `D`.
- **Jump**: Default is `W`.

You can remap these keys to your preference through the settings menu.

**Pause/Resume Game:**
- Press `Esc` to pause or resume the game.

**Cheat Code Menu:**
- Press `C` to open the cheat code menu.

**Boss Key:**
- Press `B` to activate the Boss Key overlay.

------------------------------------
            CHEAT CODES
------------------------------------
Type these codes into the cheat code menu for game altering effects:

1. **`nomove`**
   - Effect: Disables all moving platforms, making gameplay easier.

2. **`nofall`**
   - Effect: Adds a safety platform at the bottom of the screen, preventing the player from falling off.

3. **`+jump`**
   - Effect: Doubles your jump height, allowing you to reach higher platforms easily.

To deactivate a cheat:
- Enter the cheat code again.

------------------------------------
            GAMEPLAY
------------------------------------
- Your goal is to climb as high as possible without falling off the screen or hitting obstacles.
- Collect points by moving upward and avoiding falling or collisions.
- New platforms will spawn as you progress.

**Obstacle Spawning:**
- Obstacles (red circles) begin spawning after reaching a score of **100**.
- The frequency of obstacle spawning increases as your score gets higher.

**Difficulty Scaling:**
- The game gets progressively harder as your score increases:
  - Platforms may move faster.
  - Obstacles appear more frequently.

**Game Over:**
- If you fall off the screen or collide with obstacles, the game ends.

**Leaderboard:**
- Enter your initials after a game over to save your score.
- View the leaderboard from the main menu to see the top 10 scores.

------------------------------------
            SETTINGS
------------------------------------
- Access the settings menu from the main menu to remap your controls.
- Toggle **Auto Jump** on or off from the settings menu for a more automated jumping experience.
